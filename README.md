# codling-moth-model
Delay differential equation model for codling moth (Cydia pomonella) and its parasitoids, with Allee effect on fecundity. Includes bifurcation diagrams and population dynamics visualisation. 
In order for the graphic to be generated, the MD_Dynamic code must be run first. He requiers to download Julia and the different libraries in order to work.
Change the directory in the other codes to fit the location of MD_Dynamic in your files.
Changing some parameters may crash your computer, proceed with caution.

Have fun !
